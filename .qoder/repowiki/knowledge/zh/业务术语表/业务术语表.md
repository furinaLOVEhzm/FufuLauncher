### 可爱的芙芙
- 定义：本项目名称及品牌名，全称「可爱的芙芙 Minecraft 启动器」，是面向 Minecraft Java 版的第三方启动器产品。
- 别名：芙芙、FufuLauncher

### 实例
- 定义：Minecraft 游戏实例，代表一个独立的游戏配置环境，包含特定的版本、模组、Java 运行环境和配置参数。每个实例有唯一 ID，数据存储在 appmcGAME/instances 目录下。
- 别名：instance、游戏实例

### 隔离 Java
- 定义：启动器内置的独立 Java 运行环境，下载到 appmcGAME/runtimes/jdk-{major}-{arch}/ 目录，与系统 Java 完全隔离，避免版本冲突。支持多版本共存和按需下载。
- 别名：runtimes、内置Java

### 智能内存分配
- 定义：根据系统物理内存自动计算合适的 JVM 堆大小（Xmx/Xms）功能，默认开启。通过 MemoryMonitorService 监控系统内存，预留系统内存后动态分配给 Minecraft 进程，避免手动设置不当导致的性能问题。
- 别名：AutoMemoryMode、智能分配

### 多核 GC 优化
- 定义：JVM 垃圾回收器的多核优化预设，启用后自动注入 ParallelGCThreads、ConcGCThreads、CICompilerCount 等参数，利用多核 CPU 提升垃圾回收效率。参数根据物理核心数动态计算。
- 别名：MultiCoreGcOptimize、GC优化

### 设备码登录
- 定义：微软账号认证模式之一，通过 DeviceCode API 实现无头登录。用户在其他设备上输入设备码完成授权，适用于命令行或自动化场景。默认认证模式，回调端口默认 54321。
- 别名：DeviceCode、设备码认证

### 背景蒙版
- 定义：主窗口背景显示机制，支持无背景、图片背景、视频背景三种模式。通过 ThemeService 管理，使用 OverlayType 区分类型，OverlayPath 存储路径，OverlayOpacity 控制透明度。旧配置 BaseImagePath 会自动迁移。
- 别名：BackgroundEnabled、OverlayType

### 分片下载
- 定义：大文件（≥8MB）的多线程并发下载技术，将文件分成多个片段同时下载，显著提升下载速度。每个分片独立 Range 请求，完成后合并成完整文件。支持断点续传和 SHA1 校验。
- 别名：ShardDownload、多线程下载

### CPU 亲和性
- 定义：进程 CPU 绑定优化，将 Minecraft 进程限制在特定物理核心上运行，避免跨 CCD/NUMA 调度延迟。默认保留 1 个核心给系统，其余核心分配给游戏。需要管理员权限设置。
- 别名：CpuAffinityEnabled、进程绑定

### Start 文件夹
- 定义：游戏本体和应用程序文件的专用目录，严格限定只存放可执行文件和游戏本体，禁止写入配置、缓存、日志等数据。所有用户数据统一存放在 app/mcGAME 子目录中。
- 别名：ST目录、游戏目录
