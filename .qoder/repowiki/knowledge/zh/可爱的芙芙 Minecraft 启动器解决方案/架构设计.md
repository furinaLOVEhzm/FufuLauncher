根目录通过 `FufuLauncher.sln` 将两个子项目绑定为单一解决方案：`src\FufuLauncher\FufuLauncher.csproj`（.NET 8 WPF 主程序）依赖 `native\FufuNative\FufuNative.vcxproj`（C++ 原生 DLL），由 C# 通过 P/Invoke 调用其哈希与 ZIP 解压能力；`packager` 模块作为独立 Go 程序在运行期查找并启动同目录下的 `FufuLauncher.exe`；`tools_go_runtime` 提供隔离的 Go 1.26.5 工具链供打包阶段使用。整体形成「WPF UI → C# 服务层 → C++ 原生库」三层架构，并由 VS 解决方案统一配置 Debug/Release 与 x86/x64 平台矩阵。
