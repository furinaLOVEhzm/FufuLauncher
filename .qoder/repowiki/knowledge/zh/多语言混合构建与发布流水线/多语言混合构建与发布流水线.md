本项目采用 Visual Studio 2022 解决方案统一编排三种语言的构建产物：C# WPF 主程序、C++ 原生 DLL、Go 启动打包器，最终输出面向 Windows 的 Minecraft Java 版启动器。构建体系围绕 .NET SDK、MSBuild、Visual C++ 工具链和 Go 工具链协同工作，通过项目引用与 MSBuild ItemGroup 实现跨语言依赖集成。

**构建系统与工具链**
- 解决方案文件 `FufuLauncher.sln` 定义了两个核心项目：`src/FufuLauncher/FufuLauncher.csproj`（WPF 应用）和 `native/FufuNative/FufuNative.vcxproj`（C++ DLL），支持 Debug/Release × AnyCPU/x64/x86 六种配置组合。
- C# 项目使用 `.NET 8` SDK，目标框架 `net8.0-windows`，启用 WPF、Nullable、ImplicitUsings，平台目标固定为 x64，运行时标识 `win-x64`，采用非自包含模式（SelfContained=false）。
- C++ 项目使用 Visual C++ v143 工具集，C++ 标准设为 C++20，预编译头文件 pch.h/pch.cpp，输出动态库 FufuNative.dll。
- Go 打包器位于 `packager/main.go`，模块名 `fufu-packager`，Go 版本 1.21，用于查找并启动主程序。
- 辅助工具：`bootstrap/bootstrap.csproj`（一次性引导工具）、`tools/proc/proc.csproj`（进程管理工具）。

**构建流程与依赖关系**
- C++ DLL 需先用 VS2022 独立编译 `native/FufuNative/FufuNative.vcxproj`，产出按 `$(Platform)/$(Configuration)` 目录组织（如 `x64/Release/FufuNative.dll`）。
- C# 项目通过 `<ItemGroup>` 中的 `<None Include="..\..\native\FufuNative\$(Platform)\$(Configuration)\FufuNative.dll">` 将 C++ DLL 复制到输出目录，并使用 `<Link>runtimes\win-x64\native\FufuNative.dll</Link>` 重定向到 .NET 运行时目录结构。
- Go 启动器 `Start/FufuLauncher.exe` 作为入口，按优先级搜索 `FufuLauncher.exe`：同目录 → `FufuLauncher/` 子目录 → 开发路径 `src/FufuLauncher/bin/{Debug,Release}/net8.0-windows/win-x64/`。

**发布配置与产物结构**
- 发布配置文件 `src/FufuLauncher/Properties/PublishProfiles/FufuRelease.pubxml` 定义单文件发布策略：`PublishSingleFile=true`、`SelfContained=false`、仅保留 zh-CN 本地化资源、输出到 `Start/` 目录。
- 发布命令：`dotnet publish src\FufuLauncher\FufuLauncher.csproj /p:PublishProfile=FufuRelease`。
- 部署白名单：`Start/` 目录下仅允许 `FufuLauncher.exe`、`*.py` 脚本和 `appmcGAME/` 数据文件夹，其余 dll 由部署前手动清理。
- 运行环境要求：目标机器需安装 .NET 8 Desktop Runtime x64。

**版本管理与元信息**
- C# 程序集版本在 csproj 中硬编码为 `1.0.5.1`（Version/AssemblyVersion/FileVersion/InformationalVersion）。
- Go 打包器内嵌常量 `appVersion = "1.0.0.0"`，并通过 `resource.syso` 和 `versioninfo.json` 写入 Windows 文件属性。
- 版本号在各组件间未自动同步，需手动维护一致性。

**构建约束与约定**
- C++ 原生库必须与 C# 项目平台匹配（x64/x86），否则运行时加载失败。
- 发布时禁用 `IncludeNativeLibrariesForSelfExtract` 避免原生库被打包进单文件。
- 用户数据目录 `appmcGAME/` 在发布时受保护（`DeleteExistingFiles=false`），防止覆盖已存在的存档和资源。
- Go 工具链通过 `tools/go/`、`tools/gocache/`、`tools/gopath/` 隔离本地环境，根目录提供 `go1.26.5.windows-amd64.zip` 固定版本。
- 无 CI/CD 配置文件（如 GitHub Actions、Azure Pipelines），构建主要依赖本地 Visual Studio 和 dotnet CLI。
